Getting Started

Welcome to the official documentation for the Shoaib Aftab JS Framework. This framework provides Vue/React-like reactivity, SPA routing, and enterprise-grade DOM sanitization, all in a single, zero-dependency file.

<script src="path/to/shoaib-aftab.min.js"></script>

Deep Proxy Reactivity Engine

The framework uses native JavaScript Proxy to intercept changes to your state object. When a property changes, the framework uses queueMicrotask to batch updates, ensuring maximum performance without layout thrashing. 

const state = SA.Store.createState({
    user: { name: 'Shoaib' }
});

// Bind state to the DOM
SA.Store.initReactivity(document.body, state);

Now, any HTML element with sa-text="user.name" or sa-model="user.name" will automatically sync with the state!

Zero-Dependency SPA Routing

Build lightning-fast Single Page Applications using the native HTML5 History API. No page reloads required. 

// Define your routes
const routes = {
    '/': '<h1>Home Page</h1>',
    '/about': '<h1>About Us</h1>'
};

// Initialize Router
SA.Router.initRouter(routes);

Simply use <a sa-route="/about"> for navigation and <div sa-view></div> as your injection container.

Enterprise Security (DOM Sanitizer)

If you use sa-html="property", the framework automatically sanitizes the HTML string before injecting it into the DOM. It strips out <script>, <svg>, <math>, and neutralizes onerror or javascript: payload attributes to protect your users from Cross-Site Scripting (XSS).

Furthermore, the internal path resolver strictly blocks Prototype Pollution attacks by rejecting keys like __proto__ or constructor.
